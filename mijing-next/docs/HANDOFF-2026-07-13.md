## 1. 项目目的（一段话）

以两个旧微信小程序编译产物（`会员端/`、`管理端/`）为**只读考古证据**，在 `mijing-next/` 从零重建健身场馆预约 SaaS：会员端 + 员工端 uni-app（Vue 3 + TypeScript + Pinia + uView Plus）对接 Laravel 11 API。旧后端与旧数据不可恢复；新系统不追求旧库兼容，但每条能力须在追溯 CSV 中有明确处置（KEEP/REPLACE/MERGE/REJECT）。

## 2. 架构

```text
mijing-next/
├── apps/member-miniapp/   # 会员微信小程序（约课、购卡、资料、订单…）
├── apps/staff-miniapp/    # 员工微信小程序（CRM、排课、报表、设置…）
├── apps/server/           # Laravel 11 API — http://127.0.0.1:8010/api/v1
├── packages/api-client/   # OpenAPI 衍生类型/客户端
├── packages/domain-types/ # 跨端共享枚举与只读模型
└── docs/                  # 规格、矩阵、验收阶梯（本目录）
```

工作区根级 `docs/` 存放**考古追溯主账**（`traceability-*.csv`）与 L5 证据脚本（`docs/generated/`）。

身份模型要点：一个自然人一个 `Account`；Member/Staff token audience 隔离；OpenID 按 AppID 隔离；手机号/UnionID 禁止静默合并。
